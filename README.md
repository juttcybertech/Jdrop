## 🚀 Overview
**J-Drop** is a high-speed, secure local file transfer application built for seamless peer-to-peer data sharing across devices. Operating completely offline over your local network, J-Drop requires **no internet access, no user accounts, and no cloud relays** to send and receive files safely.

## ✨ Key Features
**⚡ High-Speed Local Transfer** | **🔒 End-to-End Encryption** | **🌐 100% Offline / Local Network**
**📁 Large File & Folder Support** | **📱 Cross-Device Sharing** | **🚫 No Account / No Sign-In**

---

## 🔒 Privacy & Security Commitment
**Jutt Cyber Tech Never Compromises on User Privacy.**  
J-Drop transfers your files directly between your local devices over peer-to-peer connections. Your data never touches external servers, cloud storage, or third-party networks. We strictly adhere to a zero-knowledge architecture—no logs, no tracking, and no telemetry.
